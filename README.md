## ✦ Возможности

- **Мгновенно:** конвертация происходит на вашем устройстве, без загрузки на сервер
- **Приватно:** данные не отправляются и не сохраняются
- **Без зависимостей:** HTML, CSS и чистый JavaScript, сборка не нужна
- **Два языка:** русский и английский

<br>

## ✦ Запуск

**Онлайн:** https://m0lfiln.github.io/Switch-Go/

**Локально** (сборка не нужна):

```bash
git clone https://github.com/m0lfiln/Switch-Go.git
cd Switch-Go
# откройте index.html или поднимите сервер:
python -m http.server 8000      # → http://localhost:8000
```

<br>

## ✦ Структура

| Файл | Назначение |
| :-- | :-- |
| `index.html` | разметка страницы |
| `style.css` | оформление |
| `app.js` | интерфейс и логика приложения |
| `converters.js` | функции конвертации |
| `formats.js` | описание поддерживаемых форматов |
| `i18n.js` | переводы интерфейса (RU / EN) |
